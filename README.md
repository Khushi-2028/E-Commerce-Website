# E-Commerce Shopping Management System

## Project Overview

The E-Commerce Shopping Management System is a web-based application developed using PHP and MySQL. The system allows customers to browse products, search items, add products to a shopping cart, place orders, and track order status. It also provides an admin panel for managing products, categories, offers, and customer orders.

## Features

### Customer Module

* User Registration and Login
* Product Browsing by Category
* Product Search Functionality
* Add Products to Cart
* Place Orders
* View Order Details
* Order Tracking

### Admin Module

* Admin Authentication
* Product Management
* Category Management
* Offer Management
* Order Management
* Update Order Status
* Customer Management

## Installation Steps

1. Install XAMPP or WAMP.
2. Place the project folder inside the htdocs directory.
3. Import the MySQL database into phpMyAdmin.
4. Configure database credentials in dbconnect.php.
5. Start Apache and MySQL services.
6. Open the browser and run:
   http://localhost/project-folder-name
